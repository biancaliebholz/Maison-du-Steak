# Maison du Steak

Maison du Steak is a responsive restaurant website with an interactive shopping cart, built with HTML, CSS, and JavaScript.

## Overview

The project simulates a restaurant ordering experience where users can browse available dishes, add items to their shopping cart, adjust quantities, and review their order.

The application was developed as a frontend project with a focus on interactive functionality, responsive design, and JavaScript-based shopping cart logic.

## Features

- Responsive restaurant website
- Dynamic menu display
- Add dishes to the shopping cart
- Increase and decrease item quantities
- Remove items from the shopping cart
- Automatic price calculation
- Dynamic cart updates
- Responsive layout for desktop and mobile devices

## Tech Stack

- HTML5
- CSS3
- JavaScript

No frontend framework was used.

## What I Practiced

This project was created to practice:

- JavaScript application logic
- DOM manipulation
- Dynamic content rendering
- Shopping cart functionality
- Event handling and user interactions
- Automatic price calculations
- Responsive web development
- Structuring a frontend project

## Project Background

Maison du Steak was created as a frontend development project during my software development training.

It demonstrates the implementation of an interactive restaurant interface and shopping cart functionality using HTML, CSS, and JavaScript without relying on a frontend framework.
